# Перепроектирование Maffinet Android

Дата подготовки: 4 октября 2026 года. Здесь сохранены исследование текущего проекта, предлагаемая архитектура, этапы переработки и автономный промпт. Производственный код в этой сессии не изменён. Очистка и реализация начинаются в следующей сессии.

Цель продукта: пользователь выбирает установленные приложения, подтверждает системное разрешение и получает автоматически настроенный локальный обход в пределах возможностей сети. Ручной выбор DNS, доменов и команд не должен быть обязательным шагом. Результат оценивается по трафику и сценариям выбранных приложений.

## Порядок следующих чатов

Первая сессия выполняет P00: повторный аудит фактического checkout, сохранение исходного состояния, исследование, безопасная очистка подтверждённых остатков и окончательный план. Предложения в этой папке являются отправной точкой, а не доказательством реализуемости всех механизмов.

Каждый последующий чат выполняет один следующий незавершённый этап. Он читает эту папку, проверяет Git и результаты предшественника, затем обновляет состояние и сохраняет отчёт. Он не начинает аудит заново без новой причины и не объявляет физические испытания выполненными по результатам сборки.

Фиксация этапа включает отчёт, результаты проверок, локальный Git-коммит при доступности записи в Git, оставшиеся ограничения и готовый промпт продолжения. Публикация, push и изменение другого проекта не входят в эту работу.
