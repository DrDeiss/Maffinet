## Limitations и exit

SDK36/CMake3.22.1/NDK29 с уже принятыми соглашениями отсутствуют. Ни Android Java,
ни новый JNI/CMake/native code ещё не компилировались; новые build recipes могут
потребовать исправления на provisioned host. Никакое SDK agreement не принималось.
Linux native fixture/runtime/sanitizer и device/emulator отсутствуют.
APK/source-artifact hashes, four ABIs, Android TUN/tuple/UID/control evidence,
native failure/early STOP/restart100, starts30, FD/RSS/latency/SLO не получены.
Это blockers, а не passed/skipped-as-passed результаты.

Host close100 относится к Java relay, **не к native/TUN**. Synthetic checker
fixtures не lab evidence. Нельзя утверждать physical app/LinkedIn/API/media/
ECH/QUIC/NAT64/energy/TV/16KiB acceptance. HEV остаётся кандидатом;
[ADR-001](../decisions/001-transport-prototype.md) не принимает production stack
без измерений. Firestack comparison не обоснован одним missing toolchain.

Lab relay serializes UDP roundtrips и создаёт upstream socket per datagram;
source port/throughput/general UDP acceptance ограничены. Фиксированный selected
helper и 250ms status polling — только experiment; production supervisor,
network generation/handover/ownership/UI принадлежат P02/P03. DNS здесь обычный
forwarding, не P04 broker. System DNS timeout OS-controlled. Обработка native
STOP timeout оставляет Failed с ownership, требует reap/retest, не обещает clean
restart. Конкретные pending gates в lab README и STATE.
