### Изменения и причины

- Исправлен Java admission race. При START1/START2→STOP оба old runnable могли
  увидеть сброшенный `stopRequested` и запустить TUN после STOP. Новый
  `LabStartTickets` фиксирует epoch при admission; STOP/revoke отменяют все
  ранее принятые START, cleanup не делает old ticket valid, destroy terminal.
  Explicit START после STOP остаётся разрешён после serialized cleanup.
  Duplicate START при owned session теперь ignored, не ложный Failed.
- Foreground notification повторяется на фактическом queued restart: STOP,
  выполняющийся после main-thread admission нового START, мог снять её.
  Это source fix, Android foreground/service behavior пока не compiled/verified.
- Новый `ProbeValidation`: строгие четыре IPv4 octets/hex IPv6 с colon,
  без разрешения hex-looking hostname `face` и shortened IPv4; unknown protocol
  отвергается до target socket. HTTP200 без headers/body больше не success:
  нужен complete Content-Length и точный 21-byte controlled `/p01` body.
  Raw DNS проверяет полное single compressed A/AAAA fixture answer, включая
  type/class/length/counts; empty/malformed/truncated response не passed.
  Это narrow lab contract, **не P04 broker/general HTTP or DNS client**.
- Helper report schemaVersion2 сохраняет fixture metadata/qtype. Checker требует
  A и AAAA на обоих endpoint families для UDP/TCP, verified TLS/complete HTTP/DNS
  metadata, positive distinct UIDs, finite timing и валидные original tuples.
  Snapshot содержит generation/time и должен покрывать completed runs.
  Отсутствие selected tuple/control inside/event loss продолжает reject.
- `assert` в checker/source integrity заменён explicit checks: `python -O`
  больше не отключает acceptance/source/license checks. Optimized subprocess
  rejection paths протестированы на synthetic/tmp data, не real TUN captures.
- Новый host Java contract runner компилирует actual gate/helper validation
  classes с `--release 11`. Production source/manifest/user data/prebuilts,
  pinned export/patches/lock/licenses и соседние projects не менялись.
