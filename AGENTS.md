# Maffinet Android

Работай в этом Android-проекте. Соседние проекты и Windows reference доступны
только для чтения и не задают требований Android.

Перед переработкой прочитай `docs/rebuild/START_HERE.md`, `STATE.json`,
`ROADMAP.md`, `NEXT_CHAT.md` и указанный в STATE последний отчёт сессии.
Исходный полный запрос находится в `docs/rebuild/NEXT_SESSION_PROMPT.md`.
Один чат завершает один текущий этап. Не отмечай done при невыполненных exit criteria.

Сохраняй чужие изменения и данные. Проверяй staged paths/diff; локальные
stage-коммиты разрешены, push, публикация и merge автоматически не выполняются.
Секреты, подписи, APK, приватные logs и toolchain не коммитить.
Не принимать новые SDK соглашения автоматически. Не создавать другие чаты
или subagents без отдельного разрешения пользователя.

Пустой allowlist никогда не означает весь телефон. Не ослаблять TLS/ECH,
не воспроизводить application data/0-RTT. Сохранять LICENSE/NOTICE/provenance.
JVM/сборка/проба не доказывают работу приложения на физической сети.

После этапа сохраняй `sessions/<stage>.md`, проверки, limitations, STATE и
автономный NEXT_CHAT. STATE может ссылаться на предыдущий checkpoint и subject
текущего коммита; не записывай будущий hash в содержимое самого коммита.
