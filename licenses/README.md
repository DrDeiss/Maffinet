Current upstream license files identify their projects' declared licenses; they
do not prove the provenance of unavailable custom native sources. See native
provenance and release limitations before distributing the inherited binaries.

AndroidX/Compose, Kotlin and ZXing use Apache-2.0; JNA's Apache-2.0 option is used.
Cargo.lock pins Rust dependencies but the inherited binary/source relationship
and transitive Rust notices still require a reproducible native release audit.
